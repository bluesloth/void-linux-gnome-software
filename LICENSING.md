# Licensing

`void-linux-gnome-software` is a binary **xbps package repository** (`.xbps`
packages + the signed `x86_64-repodata` index) whose packaging templates will
live in `srcpkgs/`.

No package has been published from this repository yet. When one is, its
license will be declared in the `srcpkgs/<pkg>/template` `license=` field,
following the same convention as the sibling store repositories.
